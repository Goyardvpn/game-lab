# GAME LAB

Интерактивный браузерный прототип для знакомства детей с блочным программированием и 3D-играми.

## Возможности

- Blockly: визуальные блоки, которые соединяются как в Scratch.
- Команды движения, поворота, прыжка, циклы и игровые действия.
- 3D-сцена на Three.js.
- Три демонстрационных режима: Obby, Arena и Training.
- Запуск всей программы или выполнение по одному действию.

## Запуск локально

Открой `index.html` через Live Server или любой локальный HTTP-сервер. Для загрузки Blockly, Three.js и шрифта требуется интернет.

## Публикация на GitHub Pages

1. Открой Settings → Pages в репозитории.
2. В разделе Build and deployment выбери Source: GitHub Actions.
3. После push в `main` workflow автоматически опубликует сайт.

## Важно

Это учебный прототип. Названия игровых режимов используются как жанровые ориентиры; проект не связан с Roblox, Supercell или издателями Standoff 2.
